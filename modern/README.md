# SND Noturno — migração React\n\nInterface híbrida: shell React/TypeScript, Tailwind, Radix Dialog, Lucide e Framer Motion. O motor operacional existente é preservado para manter compatibilidade com o armazenamento local. As telas internas ainda usam o renderizador legado.\n\nExecute npm install e npm run build nesta pasta. O resultado em dist pode ser publicado no mesmo endereço. Não substitua a versão atual antes de testar. A versão moderna ainda não possui service worker próprio; o offline deve ser validado antes da migração.
